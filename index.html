Solo Player "IDIOT"

Player Setup

Setup: Add and remove CPU players to play "IDIOT" with. Change the CPU difficulty and freely re-arrange the turn order. The game will start with the first player.

IDIOT is a word game. Players take turns adding one letter at a time to the start or end of the current string. The goal of the game is to not add the final letter that would form a word. The final word must be at least 4 letters long. If a player completes a word, the player loses the round.

Additionally, if any player A believes that no word contains the current string as a substring, they can "challenge" the previous player B. When "challenged", player B must come up with a word that contains the current string as a substring.

  • If no such word can be created, then player B loses the round
  • If a word can be created, then current player A loses the round

When a player loses the round, they gain a letter in "IDIOT". That player starts the next round. Once a player gains all 5 letters, they lose the game.
